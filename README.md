# pi - web OS
this is a pi-themed OS that you run in your web browser. it's a small experiment for a summer program I'm participating in.

## features
* app with the digits of pi and cool links to pi-related things
* app to play my favorite classical piano pieces
* app featuring some of my games and a link to my website

## setup
since this OS can be run in the web, there's no installation needed! simply open it in your browser at https://kpoovakan.github.io/piwebos
